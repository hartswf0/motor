CREO

The place itself becomes conversationally operable. Point at somewhere, say something ordinary, and it becomes persistent, editable, testable geometry — which the place then argues with. 82 tests.

CREO‑02 the loop

The assistant stops receiving a description of the world and starts asking it questions — what is near a point, how the ground falls, what the rain actually does, what it would cost the ground to accept a building. Every answer is computed rather than recalled, and everything except propose is read‑only.

CREO‑03 one ground

Written theory first (THEORY.md), from the defect record of the two before it: half of every fault was the same fault — two answers to one question with nothing forcing them to agree. One surface, declared resolution, labelled invention. Real parcels, real earthwork.

Terminal only, by design

WORLDTEXT MOTOR

The book was never content. The book was the dormant state of the world. Ten thousand people can exist while exactly one wakes. No viewport — that is the point of it. 36 tests.

git clone https://github.com/hartswf0/motor
cd motor/worldtext && node motor.js
Neither engine requires an API key. WORLDTEXT has a seam where one can escalate the two jobs rules cannot do — parsing arbitrary prose, and speaking in a character's own register — and anything a model produces enters as GENERATED, never as source.
